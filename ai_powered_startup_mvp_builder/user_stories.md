# User Stories - AI-Powered Startup MVP Builder

## User Story 1
As a founder, I want to input my business idea in plain text so that the AI can understand my requirements.

## User Story 2
As a developer, I want to see a generated database schema so that I can understand how my data will be structured.

## User Story 3
As a product manager, I want to export the generated code to a ZIP file so that I can run it locally on my machine.

## User Story 4
As a user, I want the system to generate API documentation automatically so that I know how to interact with the back-end.

## User Story 5
As a founder, I want to define specific constraints (like "no login") so that the MVP remains simple and focused.

## User Story 6
As a developer, I want the generated code to be in Python so that it aligns with my existing tech stack.

## User Story 7
As a user, I want to see a preview of the core features before exporting so that I can make quick adjustments.

## User Story 8
As a researcher, I want to save multiple versions of my MVP concept so that I can compare different business models.

## User Story 9
As a user, I want to receive a list of suggested tech stacks for my idea so that I can make informed infrastructure decisions.

## User Story 10
As a founder, I want a simple dashboard to manage my projects so that I can keep my ideas organized.
