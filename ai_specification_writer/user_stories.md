# User Stories

---

### User Story 1
As a student, I want to create a personalized learning roadmap so that I can follow a structured path to achieve my learning goals.

**Acceptance Criteria**:
- Student can select topics and arrange them in a preferred order.
- The roadmap is saved and visible on the dashboard after creation.
- Student can edit or update the roadmap at any time.

**Priority**: MVP

---

### User Story 2
As a developer, I want to identify my skill gaps based on a self-assessment so that I can focus on the areas I need to improve most.

**Acceptance Criteria**:
- Developer completes a skill assessment with at least 5 topic areas.
- System highlights weak areas with a visual indicator.
- Developer receives a recommended learning path based on results.

**Priority**: MVP

---

### User Story 3
As a student, I want to track my daily learning progress so that I can stay motivated and consistent in my studies.

**Acceptance Criteria**:
- Student can log completed topics each day.
- Dashboard displays a streak counter and weekly progress chart.
- System sends a reminder notification if no activity is logged by evening.

**Priority**: MVP

---

### User Story 4
As a developer, I want to receive AI-powered resource recommendations based on my current skill level so that I can learn efficiently without searching manually.

**Acceptance Criteria**:
- System analyzes current skill level and suggests at least 3 resources per topic.
- Resources are categorized by type such as video, article, and exercise.
- Developer can mark a resource as completed or save it for later.

**Priority**: High

---

### User Story 5
As a student, I want to set learning goals with deadlines so that I can manage my time and complete topics on schedule.

**Acceptance Criteria**:
- Student can create a goal with a title, description, and target date.
- System displays a countdown and progress bar toward each goal.
- Student receives a milestone alert when 50 percent and 100 percent of a goal is reached.

**Priority**: High

---

### User Story 6
As a developer, I want to connect my GitHub account so that the platform can automatically track my coding activity and reflect it in my progress.

**Acceptance Criteria**:
- Developer can link their GitHub account via OAuth.
- System fetches commit history and displays weekly coding activity.
- Coding activity contributes to the overall progress score on the dashboard.

**Priority**: High

---

### User Story 7
As a student, I want to compare my progress with peers on a leaderboard so that I can stay competitive and motivated.

**Acceptance Criteria**:
- Leaderboard displays the top 10 users ranked by weekly activity points.
- Student can see their own rank even if outside the top 10.
- Leaderboard refreshes weekly and resets rankings every month.

**Priority**: Medium

---

### User Story 8
As a developer, I want to follow a structured skill roadmap for a specific technology so that I can progress from beginner to advanced in a clear sequence.

**Acceptance Criteria**:
- Developer can browse and select from at least 5 predefined technology roadmaps.
- Each roadmap shows topics in sequential order with estimated completion times.
- Completed topics are visually marked and locked topics become available as prerequisites are met.

**Priority**: Medium

---

### User Story 9
As a student, I want to receive daily study recommendations so that I know exactly what to focus on each day without feeling overwhelmed.

**Acceptance Criteria**:
- System generates a daily study plan based on the student roadmap and available time.
- Recommendations include no more than 3 tasks per day.
- Student can accept, skip, or reschedule each recommended task.

**Priority**: Medium

---

### User Story 10
As a developer, I want to view a visual dashboard of my learning statistics so that I can understand my progress at a glance.

**Acceptance Criteria**:
- Dashboard displays total topics completed, hours studied, and active streak.
- Charts show progress over the past 7 days and 30 days.
- Developer can filter the dashboard by technology or topic category.

**Priority**: Low

---

### User Story 11
As a student, I want to earn badges and rewards for completing milestones so that I feel recognized for my achievements.

**Acceptance Criteria**:
- System awards a badge when a student completes a full roadmap section.
- Badges are displayed on the student profile page.
- Student receives an in-app notification when a new badge is earned.

**Priority**: Low

---

### User Story 12
As a developer, I want to export my learning progress as a PDF report so that I can share it with employers or mentors.

**Acceptance Criteria**:
- Developer can generate a PDF from the dashboard with one click.
- Report includes completed topics, skills acquired, and GitHub activity summary.
- PDF is downloadable and includes the date of generation.

**Priority**: Low
