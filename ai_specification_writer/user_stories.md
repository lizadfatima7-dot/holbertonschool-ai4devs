# User Stories

## User Story 1
**As a** Student, **I want to** create a personalized learning roadmap **so that** I can follow a structured path to achieve my learning goals.
- **Acceptance Criteria 1**: User can select topics and arrange them in a preferred order.
- **Acceptance Criteria 2**: User can save the roadmap and access it from the dashboard at any time.
- **Acceptance Criteria 3**: User can edit or delete topics from the roadmap after creation.
**Priority**: MVP

---

## User Story 2
**As a** Developer, **I want to** complete a skill assessment **so that** I can identify my skill gaps and receive a recommended learning path.
- **Acceptance Criteria 1**: User can complete a self-assessment covering at least 5 topic areas.
- **Acceptance Criteria 2**: User receives a visual report highlighting weak and strong areas after submission.
- **Acceptance Criteria 3**: User is presented with a recommended learning path based on assessment results.
**Priority**: MVP

---

## User Story 3
**As a** Student, **I want to** track my daily learning progress **so that** I can stay consistent and motivated throughout my studies.
- **Acceptance Criteria 1**: User can log completed topics each day from the dashboard.
- **Acceptance Criteria 2**: User can view a streak counter and weekly progress chart on the main screen.
- **Acceptance Criteria 3**: User receives a reminder notification if no activity has been logged by the end of the day.
**Priority**: MVP

---

## User Story 4
**As a** Developer, **I want to** receive AI-powered resource recommendations **so that** I can learn efficiently without searching for materials manually.
- **Acceptance Criteria 1**: User receives at least 3 recommended resources per topic based on current skill level.
- **Acceptance Criteria 2**: User can filter resources by type including video, article, and exercise.
- **Acceptance Criteria 3**: User can mark a resource as completed or save it to a personal reading list.
**Priority**: MVP

---

## User Story 5
**As a** Student, **I want to** set learning goals with deadlines **so that** I can manage my time and complete topics according to a schedule.
- **Acceptance Criteria 1**: User can create a goal with a title, description, and target completion date.
- **Acceptance Criteria 2**: User can view a progress bar and countdown timer for each active goal.
- **Acceptance Criteria 3**: User receives an alert when 50 percent and 100 percent of a goal is completed.
**Priority**: High

---

## User Story 6
**As a** Developer, **I want to** connect my GitHub account **so that** the platform can automatically track my coding activity and reflect it in my progress.
- **Acceptance Criteria 1**: User can link a GitHub account using OAuth authentication.
- **Acceptance Criteria 2**: User can view weekly coding activity fetched from GitHub commit history.
- **Acceptance Criteria 3**: User sees coding activity reflected as points in the overall progress score.
**Priority**: High

---

## User Story 7
**As a** Student, **I want to** compare my progress with peers on a leaderboard **so that** I can stay competitive and motivated.
- **Acceptance Criteria 1**: User can view a leaderboard showing the top 10 users ranked by weekly activity points.
- **Acceptance Criteria 2**: User can see their own rank on the leaderboard even if outside the top 10.
- **Acceptance Criteria 3**: User can see the leaderboard reset and refresh on a weekly basis.
**Priority**: Medium

---

## User Story 8
**As a** Developer, **I want to** follow a predefined technology roadmap **so that** I can progress from beginner to advanced level in a clear and structured sequence.
- **Acceptance Criteria 1**: User can browse and select from at least 5 predefined technology roadmaps.
- **Acceptance Criteria 2**: User can view topics in sequential order with estimated completion times for each.
- **Acceptance Criteria 3**: User can see completed topics marked visually and locked topics unlocked as prerequisites are met.
**Priority**: Medium

---

## User Story 9
**As a** Student, **I want to** receive daily study recommendations **so that** I know what to focus on each day without feeling overwhelmed.
- **Acceptance Criteria 1**: User receives a daily study plan generated from their active roadmap and available time.
- **Acceptance Criteria 2**: User sees no more than 3 recommended tasks per day on the dashboard.
- **Acceptance Criteria 3**: User can accept, skip, or reschedule each recommended task individually.
**Priority**: Medium

---

## User Story 10
**As a** Developer, **I want to** view a visual learning statistics dashboard **so that** I can understand my overall progress at a glance.
- **Acceptance Criteria 1**: User can view total topics completed, hours studied, and current active streak.
- **Acceptance Criteria 2**: User can view progress charts showing activity over the past 7 and 30 days.
- **Acceptance Criteria 3**: User can filter dashboard statistics by technology category or topic.
**Priority**: Low

---

## User Story 11
**As a** Student, **I want to** earn badges for completing milestones **so that** I feel recognized and encouraged to continue learning.
- **Acceptance Criteria 1**: User receives a badge automatically when a full roadmap section is completed.
- **Acceptance Criteria 2**: User can view all earned badges displayed on their profile page.
- **Acceptance Criteria 3**: User receives an in-app notification each time a new badge is awarded.
**Priority**: Low

---

## User Story 12
**As a** Developer, **I want to** export my learning progress as a PDF report **so that** I can share my achievements with employers or mentors.
- **Acceptance Criteria 1**: User can generate and download a PDF report from the dashboard with one click.
- **Acceptance Criteria 2**: User sees the report include completed topics, acquired skills, and GitHub activity summary.
- **Acceptance Criteria 3**: User can view the generation date printed on the exported PDF document.
**Priority**: Low
